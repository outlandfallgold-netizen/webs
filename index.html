Quantity from the box label — anywhere from 5 to 1,000+ pieces; the box is scrapped, so only the parts ship. Parts are stacked flat in straight rows, so every row holds the same count and rows are easy to count off. Leave parts per layer blank and it is counted off the size; type the number that really goes on and the layers, height and weight follow your count. Parts slid under each other with the spouts alternating pack tighter than the size allows, so type what the floor does; add parts per row and the card names the rows again.
